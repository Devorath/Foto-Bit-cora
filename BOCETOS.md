# Bocetos / wireframes de FotoBitácora

Puedes conforme al proyecto que serán replicados en Balsamiq.

## Pantalla 1: Registro

```text
┌─────────────────────────────────┐
│          CREAR CUENTA           │
│                                 │
│ [ Nombre(s)                   ] │
│ [ Apellidos                   ] │
│ [ Correo electrónico          ] │
│ [ Contraseña                  ] │
│ [ Confirmar contraseña        ] │
│                                 │
│ [      Registrar usuario      ] │
│ [       Ya tengo cuenta       ] │
└─────────────────────────────────┘
```

## Pantalla 2: Inicio de sesión

┌─────────────────────────────────┐
│            FotoBitácora         │

│          INICIAR SESIÓN         │

│ [           Ingresar          ] │
